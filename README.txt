# Updated Sagar Timalsina Dynamic Portfolio Template

Open index.html in a browser.

Main update file:
- data.js

You can change:
- Education addresses
- Detailed read-more descriptions
- External links
- Experience bullet points
- Project bullet points and GitHub links
- Skills categories
- Certification names and certificate image links

For certification links:
1. Upload certificate images into the same folder, or use Google Drive public links.
2. Replace imageName/link inside data.js.

Files:
- index.html
- styles.css
- data.js
- script.js
